# macOS Administration Scripts

Bash scripts for managing Macs. Some are meant to run from Jamf Pro.

## Scripts

| Script | Description |
| --- | --- |
| [configure-mau-autoupdate](office/configure-mau-autoupdate/) | Sets Microsoft AutoUpdate to automatically download and install Microsoft 365 updates for the logged-in user. |

## Disclaimer

These scripts are provided as is. Test them on non-production Macs first, and use them at your own risk.
